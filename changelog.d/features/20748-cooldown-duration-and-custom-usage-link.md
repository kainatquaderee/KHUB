- **feat(resilience):** per-provider **Retry delay** control on the provider page — set a fixed rate-limit cooldown from a preset (15s / 30s / 60s / 2m / 5m / 15m / 30m / 1h / 6h / 12h / 1d / 7d / 30d) or any custom duration, saved to `resilience.providerQuotaOverrides[provider].rateLimitCooldownSeconds`. It replaces the scaled exponential backoff only when the upstream sent no retry hint, so 5xx/capacity errors keep their backoff; a per-connection `rotationOverrides.rateLimitResetSeconds` still wins.
- **feat(resilience):** per-provider **Custom usage link** — point a provider at an HTTP endpoint that reports the account's allowance (e.g. a `GET .../free-tier`). OmniRoute reads `remaining`/`total`/`used`/`resetAt` from it through the same reader a connection-level `quotaEndpoint` uses (the connection value still wins), and the card carries a one-click **Test** that probes the URL through the outbound URL policy so you can confirm the link works before relying on it.
- **feat(resilience):** provider `resetAt`/`resets-in` cooldowns no longer clamp to the account-level max-cooldown cap, so a genuine multi-day upstream reset (e.g. a 7-day cap) is honoured instead of being silently shortened.
